# **Pinned, alone in this file, because ruff's OUTPUT is a CI gate.**
#
# `ruff format --check` fails on a difference between what the formatter produces and
# what is committed -- so a new ruff release turns main red with nobody having touched
# the code. That is what happened on 2026-08-30: four test files CI had accepted for
# weeks began failing because a newer ruff could fit their wrapped expressions on one
# line. Nothing was wrong with them, and no commit caused it.
#
# Every other tool here floats on purpose: a newer httpx or pytest changes what is
# TESTED, and catching that drift early is the point. A newer formatter changes what is
# WRITTEN, which is not a signal about this code at all. Bump this line deliberately and
# run `ruff format app scripts tests tools` in the same commit.
